Все функции системы объединены в **единый веб-портал на одном российском сервере**:
* **Личный кабинет куратора** с закрытым белым списком и входом по Email OTP (сессия 10 дней).
* **Панель старшего куратора**: добавление email новых кураторов, управление ролями (повышение до старшего) и блокировка.
* **Эксклюзивный редактор системного промпта нейросети GigaChat-2-Pro** (только для старших кураторов с 2FA-подтверждением).
* **Форма отправки встреч КТалк на анализ** с прогресс-баром в реальном времени.
* **Интерактивный дашборд преподавателей** с оценками по 21 критерию, таймкодами нарушений и **экспортом в Excel (.xlsx)**.
* **База данных PostgreSQL 16** в изолированном томе с соблюдением 152-ФЗ.

## 1. Системные требования к серверу (VPS)

Для работы всей системы достаточно **одного виртуального сервера в РФ** (дата-центр Москва или Санкт-Петербург):
* **Процессор:** 2 vCPU
* **Оперативная память (RAM):** 2 – 4 ГБ
* **Диск:** 40 – 60 ГБ NVMe/SSD
* **ОС:** Ubuntu 22.04 LTS или Ubuntu 24.04 LTS
* **Провайдеры с оплатой картами РФ / СБП:** 
  * **VDSina.ru** (тариф «Стандартный 2 GB», Москва — **600 ₽/мес**)
  * **FirstVDS.ru** (тариф «Разгон», Москва — **~919 – 1 069 ₽/мес**)

## 2. Шаг 1: Первичная настройка сервера (SSH)

Подключитесь к вашему серверу через терминал:
```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```

Обновите систему и установите Docker одной официальной командой:
```bash
# 1. Обновление пакетов
apt-get update && apt-get upgrade -y

# 2. Установка базовых утилит
apt-get install -y curl git ufw ca-certificates nano

# 3. Установка Docker и Docker Compose V2
curl -fsSL https://get.docker.com | sh

# 4. Проверка установки:
docker --version
docker compose version
```

## 3. Шаг 2: Клонирование и настройка проекта

1. Склонируйте проект в рабочую директорию (или загрузите архив):
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> /opt/olymp_portal
cd /opt/olymp_portal
```

2. Создайте файл конфигурации `.env` из шаблона:
```bash
cp .env.example .env
nano .env
```

3. Заполните ключевые переменные в `.env`:
```env
# 1. Порт веб-приложения (по умолчанию 3000)
PORT=3000

# 2. База данных PostgreSQL 16
DB_USER=postgres
DB_PASSWORD=УкажитеСложныйПарольБД123!
DB_NAME=lecture_db
DB_PORT=5432

# 3. Токен КТалк API для скачивания записей вебинаров
TALK_API_KEY=ваш_ключ_из_личного_кабинета_кталк

# 4. Авторизация в Сбер GigaChat-2-Pro
GIGACHAT_CREDENTIALS=ваш_токен_авторизации_сбера_base64
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2-Pro

# 5. Секретный криптографический ключ подписи сессий (10 дней)
TOKEN_SECRET=сгенерируйте_случайную_строку_из_32_символов

# 6. Почтовый шлюз SMTP для отправки кодов на Email (Яндекс, Mail.ru, VK WorkMail)
# Если оставить пустым, сервер будет писать коды в консоль (режим dev)
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=auth@olympiadpractices.ru
SMTP_PASS=пароль_приложений_16_символов
SMTP_FROM="Олимпиадные Практики <auth@olympiadpractices.ru>"
```

## 4. Шаг 3: Настройка сетевого экрана (Брандмауэр UFW)

Защитите сервер от внешнего сканирования, оставив открытыми только веб-порты и SSH:
```bash
# Разрешаем SSH для управления
sudo ufw allow 22/tcp

# Разрешаем веб-порты для сайта и отчетов
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 3000/tcp

# Включаем брандмауэр
sudo ufw enable
sudo ufw status
```
*Порт базы данных PostgreSQL (5432) изолирован внутри Docker-сети и недоступен злоумышленникам из интернета.*

## 5. Шаг 4: Запуск контейнеров

В директории `/opt/olymp_portal` выполните сборку и запуск:
```bash
docker compose up -d --build
```

Проверьте статус запущенных контейнеров:
```bash
docker compose ps
```
Оба сервиса (`lecture-ai-postgres` и `lecture-ai-checker`) должны иметь статус **Up (healthy)**.

Просмотр логов веб-сервера и отправки писем:
```bash
docker compose logs -f app
```

1. Откройте в браузере: `http://IP_ВАШЕГО_СЕРВЕРА:3000`
2. В поле Email введите адрес начального старшего куратора:
   `shurygin.egor2009@gmail.com`
3. Нажмите **«Получить код подтверждения»**.
   * Если настроен `SMTP_*`: 6-значный код придет на вашу почту.
   * Если SMTP еще не настроен: код отобразится в терминале сервера (`docker compose logs -f app`) и в окне входа.
4. Введите 6-значный код.
5. Вы успешно вошли как **Старший куратор (Руководитель)**! Сессия активна **10 дней**.

## 7. Шаг 6: Добавление сотрудников и назначение ролей

1. В верхнем меню перейдите во вкладку **«Управление кураторами»** (доступна только старшим кураторам).
2. В форме «Добавить email куратора в белый список» введите email нового методиста (например, `anna@olympiadpractices.ru`), его ФИО и выберите роль (`Куратор` или `Старший куратор`).
3. Нажмите **«Добавить в белый список»**.
4. Теперь этот сотрудник сможет зайти на сайт по своему email.
5. В любой момент вы можете нажать кнопку **«Назначить старшим»** или **«Снять права старшего»** прямо в таблице.

## 8. Шаг 7: Подключение домена и бесплатного SSL (HTTPS)

Чтобы портал открывался по красивому адресу `https://metodist.olympiadpractices.ru`:

1. В DNS вашего домена добавьте **A-запись**:
   * Имя: `metodist`
   * Значение (IP): `IP_ВАШЕГО_СЕРВЕРА`

2. На сервере установите Nginx и Certbot:
   ```bash
   apt-get install -y nginx certbot python3-certbot-nginx
   ```

3. Создайте файл конфигурации `/etc/nginx/sites-available/olymp`:
   ```nginx
   server {
       server_name metodist.olympiadpractices.ru;

       location / {
           proxy_pass http://127.0.0.1:3000;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
           proxy_read_timeout 300s;
           client_max_body_size 500M;
       }
   }
   ```

4. Активируйте сайт и выпустите SSL-сертификат:
   ```bash
   ln -s /etc/nginx/sites-available/olymp /etc/nginx/sites-enabled/
   nginx -t && systemctl reload nginx
   certbot --nginx -d metodist.olympiadpractices.ru
   ```

Теперь портал защищен зеленым замком HTTPS, а авторизация и выгрузки работают на максимальной скорости.

## 9. Полезные команды обслуживания

* **Перезапуск контейнеров:**
  ```bash
  docker compose restart
  ```
* **Обновление проекта до последней версии:**
  ```bash
  git pull
  docker compose up -d --build
  ```
* **Резервная копия базы данных:**
  ```bash
  docker compose exec -t postgres pg_dump -U postgres lecture_db > backup_$(date +%Y%m%d).sql
  ```
* **Все данные (кураторы, задачи, тексты промптов)** сохраняются на хосте в папке `/opt/olymp_portal/data` и в томе `postgres_data`, поэтому они **никогда не стираются** при перезапусках контейнеров.
